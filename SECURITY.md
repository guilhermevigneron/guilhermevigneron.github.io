# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability on `guilhermevigneron.dev` or within this repository, please report it responsibly via email:

- **Contact:** [email@gvo.simplelogin.com](mailto:email@gvo.simplelogin.com)
- **Preferred Languages:** English (`en`), Portuguese (`pt`)
- **Machine-Readable Policy:** [https://guilhermevigneron.dev/.well-known/security.txt](https://guilhermevigneron.dev/.well-known/security.txt)

Please include a clear description of the issue, steps to reproduce, and any relevant proof-of-concept details. You can expect an initial acknowledgment within a few business days.
