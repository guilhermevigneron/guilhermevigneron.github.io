# Guilherme Vigneron - Portfolio & Resume

![CI](https://github.com/guilhermevigneron/guilhermevigneron.github.io/actions/workflows/ci.yml/badge.svg)

This repository contains the source code for my personal portfolio and resume website (**[guilhermevigneron.dev](https://guilhermevigneron.dev)**). It is engineered as a **zero-third-party-dependency, self-verifying static showcase** with a pure Node build pipeline, automated headless-Chromium resume PDF generation, and a live CI quality dashboard.

---

## Architecture & Key Capabilities

### 1. Zero Third-Party Runtime Dependencies & Performance
- **Minimalist CV Aesthetic:** Monochrome warm off-white light mode (`#fafaf8`) and automatic/toggleable dark mode (`#0d0c0a`), print-first A4 typography, and responsive command palette (`Ctrl+J` / `⌘+J` on desktop, touch search trigger on mobile).
- **Split & Fingerprinted CSS Bundles:** Minified screen ([src/styles.css](src/styles.css)), subpage ([src/subpage.css](src/subpage.css)), and print ([src/print.css](src/print.css)) CSS bundles with SHA-256 asset fingerprinting and HTML minification ([scripts/minify-html.mjs](scripts/minify-html.mjs)).
- **Self-Hosted Subsetted Typography & Responsive Avatar:** Latin-subsetted `Geist Mono` (`400..500`) and `Geist Pixel Square` with metric-matched fallbacks (`CLS = 0`), responsive `<picture>` AVIF/WebP/JPEG avatar variants, and self-hosted SVG/PNG/ICO favicons — zero external requests.
- **Inline Accessible SVGs:** All social and UI icons are clean inline `<svg>` elements (`aria-hidden="true"`, `focusable="false"`), eliminating Font Awesome CDN requests.
- **Light/Dark Theme & Print Layout:** Zero-dependency toggle respecting `prefers-color-scheme` and syncing mobile `<meta name="theme-color">` with `localStorage` persistence (`assets/js/theme.js`), paired with `@media print` rules for clean single-page A4 printing.

### 2. Single Source of Truth & Machine-Readable Endpoints
- **`/resume.json`:** Standardized JSON Resume file driving automated synchronization (`scripts/sync-resume.mjs`) for Schema.org `Person` JSON-LD in `index.html` and `/llms.txt`, verified against DOM content by `scripts/validate-sync.mjs`.
- **`/.well-known/security.txt`:** RFC 9116 compliant vulnerability disclosure policy with automated CI expiry checks (fails if fewer than 30 days remain).
- **`/404.html` & `/sitemap.xml`:** Branded 404 recovery page and sitemap matching `robots.txt`.

### 3. Automated `/resume.pdf` Pipeline
- **`scripts/generate-pdf.mjs`:** Uses headless Chromium via `playwright-core` against the built local `_site/index.html` (blocking any external requests) to generate a crisp, self-hosted `/resume.pdf` on every build.

### 4. Continuous Verification & `/quality/` Dashboard
- **`npm run test:security`:** Fails if `npm audit --audit-level=high` detects vulnerabilities.
- **`npm run test:html`:** Runs offline HTML5 validation (`html-validate`) across every generated HTML artifact (`index.html`, `404.html`, `quality/index.html`).
- **`npm run test:perf`:** Runs headless mobile emulation (`scripts/check-performance.mjs`) enforcing asset byte budgets, Web Vitals (`FCP`, `LCP`, `CLS`), zero 404s, and zero horizontal overflow across `320px–768px` viewports.
- **`lychee-action`:** Crawls internal assets and external links during CI and runs weekly on `schedule` (`cron`) + `workflow_dispatch` against `https://guilhermevigneron.dev` alongside `npm run test:smoke:prod`.
- **Cypress + `cypress-axe`:** Verifies zero external third-party network requests, mobile compatibility (`>=44px` touch targets, `320px–768px` layout, mobile command palette), `/resume.pdf` binary validity, `security.txt` freshness, `resume.json`/`llms.txt`/JSON-LD parity, theme persistence, and 12-audit WCAG 2.1 AA compliance across Light & Dark themes on Mobile and Desktop viewports.
- **`/quality/`:** Publishes a live static verification summary generated by `scripts/generate-quality-report.mjs` and linked from the portfolio footer.

## Local Development

```bash
npm ci
npm run build
npm run test:html
npm run test:perf    # Runs Playwright mobile Web Vitals & asset budget audit
npm run test:e2e     # Starts static server & runs Cypress + mobile + axe suite
```
